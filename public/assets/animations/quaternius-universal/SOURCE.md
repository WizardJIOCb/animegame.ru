# Quaternius Universal Animation Library

`UAL1_Standard.glb` comes from the
[Quaternius Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html).

The non-root-motion Standard export is used so that game navigation controls the
character position while the animation mixer controls the skeleton. The pack is
published under CC0 1.0; a copy of its license notice is included in `LICENSE.txt`.
